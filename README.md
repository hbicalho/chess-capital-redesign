# Chess Capital · redesign do site

Prévia do novo site da Chess Capital, em HTML, CSS e JavaScript estáticos, sem framework e sem etapa de build.

## Estrutura

- `index.html` e uma página `.html` por seção: Quem somos, Gestão de Fundos, Gestão de Patrimônio, as cinco fichas de fundo, Documentos e Políticas, Privacidade e Cookies
- `assets/site.css` e `assets/site.js`
- `assets/img` e `assets/video` com fotos, logo, selos e o vídeo da capa

## Ver localmente

Abra `index.html` no navegador ou rode `python3 -m http.server` nesta pasta.

## Publicação

A prévia roda no GitHub Pages. O formulário de contato e os PDFs dos documentos só funcionam na versão publicada na hospedagem da Chess.
